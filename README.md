# HydroChamber™ | Phygital Smart Hydration Platform

> ** Kasem Bundit University (KBU) Digital Business & Application Showcase Project **

HydroChamber™ is an innovative phygital (physical + digital) smart shaker and tumbler ecosystem featuring built-in 360° articulating MagSafe phone stand mounts, NFC tap-to-sync hydration tracking, and industrial fiber laser customization.

---

## 🚀 Live Demo & Vercel Deployment

This repository is structured for instant zero-config deployment on **Vercel**.

1. Import this repository into your Vercel Dashboard (`https://github.com/devtint/HydroChamber`).
2. Framework Preset: **Other / None (Static HTML)**.
3. Root Directory: `./` (Repository root).
4. Click **Deploy**.

---

## ✨ Features

- **MagSafe 360° Articulating Stand**: Multi-angle phone holder for filming workouts, watching study lectures, or hands-free calls.
- **NFC Phygital Sync**: Built-in NFC chip in the base for instant LINE OA and hydration app pairing.
- **Industrial Fiber Laser Personalization**: Real-time laser etching preview engine.
- **Dynamic Light & Dark Themes**: High-contrast, accessibility-focused light theme by default with seamless toggle switch.
- **Interactive 3D Configurator**: Live colorway previews (Matcha Sage, Oat Milk Cream, Lavender Haze, Slate Charcoal), custom laser text, and add-on selection.
- **Ecosystem Add-ons**: Electrolyte Stick Packs (฿169) and Magnetic Carabiner Cap (฿220).
